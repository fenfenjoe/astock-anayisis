- **auto_fix_eligible**: true

- **预期行为**: 调度任务执行失败（`status == "failed"`）且已建工单时，应生成一条"任务失败"提示（notice）告知用户，与 BUG 工单联动
- **实际行为**: `scheduler_agent.py:341-346` 调用
  ```python

      kind="notice",
      title=f"调度任务 {task.get('task_id')} 执行失败",

  ```
  而被调用方 `agent/core/notices.py:57` 的签名是 `create_review_done_notice(summary, db=None)`：
  - 四个关键字参数全部不存在（`kind` / `title` / `content` / `source`）；
  - 必填位置参数 `summary` 未提供；
  - → 抛 `TypeError: create_review_done_notice() got an unexpected keyword argument 'kind'`；
  - 该调用被外层 `try/except Exception: pass`（L347-348）**静默吞掉** → 失败通知永远不生成，且无任何日志。

  3. 走真实路径：`scheduler_agent._handle_task_result(task, {'status':'failed', ...})` → 异常被 except 吞掉，`agent_notices` 无新增记录
- **受影响文件**:

- **建议修复**: 将调用点改为 callee 支持的 API（推荐直接用底层函数以获得自定义标题/内容）：
  ```python

      "notice",
      f"调度任务 {task.get('task_id')} 执行失败",

  )
  ```
  或按 callee 契约传一句话 summary：`notices_mod.create_review_done_notice(f"调度任务 {task.get('task_id')} 执行失败，工单 {ticket_id} 已创建")`。同时建议给该 `except` 补 `logging.warning`，避免再次静默。
