# BUG-005: 胜率计算分母与正确性定义不符（非零收益天数 vs 总交易日数）

- **组件**: metrics
- **严重程度**: MEDIUM
- **违反的正确性定义**: MET-005（胜率 = 日收益 > 0 的天数 / 总交易日数）
- **状态**: MANUAL_REVIEW
- **auto_fix_eligible**: false
  - 判定理由：涉及计算公式口径（MET-005），分母取"总交易日数"还是"非零收益天数"属指标口径决策，需人工判断，不机械修复
- **发现时间**: 2026-08-27T12:21 CST
- **发现方式**: 每日代码巡检
- **预期行为**: `correctness_definitions.yaml` MET-005 定义 `win_rate = (daily_returns > 0).sum() / len(daily_returns)`，即分母为**总交易日数**
- **实际行为**: `backtest/metrics.py` L27-28 实现为：
  ```python
  nonzero = (rets != 0).sum()
  win_rate = (rets > 0).sum() / nonzero if nonzero > 0 else 0.0
  ```
  分母为**非零收益天数**（`(rets != 0).sum()`），排除了收益恰为 0 的交易日。`tests/test_metrics.py::test_win_rate` 也按实现口径断言：`rets = [0.0, 0.01, 0.02, -0.01, 0.03]`（5 个交易日，3 正 1 负 1 零）→ 断言 0.75 = 3/4，而按定义应为 3/5 = 0.6
- **复现步骤**:
  1. `cd etf-strategies && python -c "import pandas as pd; from backtest.engine import BacktestResult; from backtest.metrics import compute_metrics; nav=(1+pd.Series([0.0,0.01,0.02,-0.01,0.03])).cumprod(); r=BacktestResult(nav=nav, returns=pd.Series([0.0,0.01,0.02,-0.01,0.03]), weights=pd.DataFrame({'A':1.0}, index=nav.index), turnover=1.0); print(compute_metrics(r)['win_rate'])"` → 输出 0.75
  2. 按 MET-005 定义应为 0.6（3 正 / 5 总交易日）
- **受影响文件**:
  - `etf-strategies/backtest/metrics.py:27-28`
  - `etf-strategies/tests/test_metrics.py:39-44`（测试按实现口径断言，未校验定义）
- **潜在影响**: 胜率指标系统性偏高（含现金/停牌零收益日的策略偏差更大），影响 Dashboard 策略排序与回测报告中的胜率展示；与 correctness_definitions 声明的口径不一致
- **建议修复**: 人工确认胜率口径后，将分母改为总交易日数 `len(rets)` 并同步修正 `test_win_rate` 期望值，或更新 correctness_definitions.yaml MET-005 定义说明"分母为交易日总数"（二选一，需一致性）
