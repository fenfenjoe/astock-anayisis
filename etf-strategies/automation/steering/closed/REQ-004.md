## 需求描述

**背景**：`backtest/data.py get_kline()` 目前**单源依赖东财 push2his**（经 `em_client.em_get` 限流）。东财对部分大陆住宅 IP 间歇风控（HTTP 000/空数据/RemoteDisconnected），已连续触发大量数据 BUG（BUG-016/019/020/021/022/026/033/034/040/052/054/055/057/058），实测 2026-10-10 仍不可达。单源依赖导致任何东财波动都会中断盘中信号与数据刷新。

**调研结论**（`docs/2026-10-10-免费实时行情数据源稳定性调研.md`）：
- 腾讯财经（qt.gtimg.cn / ifzq.gtimg.cn）为免费源事实首选：不封IP、海外可直连、批量实时报价 + 分钟K（前复权）+ 分时 + 当日逐笔
- mootdx 行情命令 2026-09 起失效，应彻底退出行情层
- 多源容错架构：**腾讯(主) → 东财em_get(备+独有) → 新浪(兜底) → 本地parquet缓存**，配健康探测/自动切换/交叉校验

## 期望结果

1. **多源降级**：`get_kline()` 东财失败 → 自动切腾讯日K → 再失败读本地缓存 → 全失败才报错；切换不静默（打印 WARN）
2. **腾讯客户端**：新增 `backtest/tencent_client.py`（实时报价 `tencent_quote` + 日K `tencent_daily_kline` + 分钟K `tencent_mkline`），复用 a-stock-data 的 `tencent_quote()` 实现
3. **健康探测 + 自动切换**：跟踪源状态（连续失败 N 次标记 down、恢复探测后回切），行情入口抽象 `QuoteSource` 接口（为未来 miniQMT 预留位）
4. **交叉校验**：双源价差校验（ETF 价差 >0.5% 告警），校验失败不静默
5. **可验证**：新增测试覆盖「东财失败自动切腾讯」「腾讯失败切缓存」「全失败报错」「双源价差校验」「源状态切换」，全量测试无回归
