## 1. 目标与范围

### 1.1 目标
在 A 股真实数据上，对 4 个代表性 ETF 策略做严谨回测，输出含收益/风险指标与可视化曲线的回测报告。框架需：可证伪（规则化）、可解释（知道赚什么溢价）、可执行（计入成本、防前视偏差）。

### 1.2 落地策略（精简 4 个，覆盖 4 大族系）

| 编号 | 策略 | 族系 | 信号规则 | 标的 |
|---|---|---|---|---|
| S1 | 买入持有 | 被动 | 恒满仓沪深300，不调仓 | 510300 |
| S2 | 双动量 | 动量 | 沪深300过去 250 交易日收益>0 且 >国债收益 → 持股；否则切国债/货币 | 510300 / 511260 / 511880 |
| S3 | 均线趋势 | 趋势 | 20日收盘均线上穿60日线 → 持股；下穿 → 切货币 | 510300 / 511880 |
| S6 | 60/40 股债平衡 | 配置 | 60%股+40%债，季末再平衡 | 510300 / 511260 |

> S1 同时充当所有策略的基准 benchmark。

### 1.3 回测窗口
- **起始**：2012-05-28（510300 上市次日，数据主链路最早可得日）。
- **结束**：数据时点 2026-07-01（最新交易日）。
- **公共起始对齐**：511260 国债ETF、511880 货币ETF 上市晚于 510300；多资产策略（S2/S6）实际起始日取**所有涉及标的的公共首个交易日**，缺口段记 NaN 不外推，避免生存者偏差。
- 预计公共起始约 2013 年前后（实现时以实际数据为准并在报告中标注）。

## 3. 数据层

### 3.1 数据主链路（已 smoke test 验证）

**东财 push2his 前复权日 K**：
```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
params: secid={1或0}.{code}, klt=101(日K), fqt=1(前复权),
        beg=20120101, end=20261231,
        fields1=f1,f2,f3,f4,f5,f6,
        fields2=f51,f52,f53,f54,f55,f56,f57,f58  # 日期,开,收,高,低,量,额,振幅
```
返回 `data.klines` 为逗号分隔字符串列表，解析为 DataFrame。实测 510300 返回 3424 根（2012-05-28 至今，已前复权）。

**关键点**：`fqt=1` 已前复权 → 收益直接算，无需手工除权（ETF 分红频繁，不复权会虚高）。

### 3.2 防封（遵守 CLAUDE.md 东财限流铁律）
- 所有东财请求走 `em_get()`：串行限流（`EM_MIN_INTERVAL=1.0s` + 随机抖动）+ 复用 Keep-Alive session + 默认 UA + 429/5xx 指数退避重试（403 不重试）。
- 复用 SKILL.md 提供的 `em_get` / `EM_SESSION` / `tdx_client()` helper 实现。

### 3.3 本地缓存
- 首次拉取存 `backtest/cache/{code}.parquet`，二次跑直接读缓存（标注缓存日期），免重拉、免反复触发风控。
- 提供强制刷新开关 `refresh=True`。

### 3.4 兜底
- 东财持续失败时，mootdx `bars(frequency=9)` 取近 3 年**不复权**日 K（仅近期短历史场景可用，需在报告标注"不复权"）。
- mootdx 走 `tdx_client()` helper 规避 0.11.x BESTIP bug。

### 3.5 数据不足处理
- 任一标的拉取失败或返回空 → **明确报错并提示换网络**，不静默编造数据（CLAUDE.md 铁律）。

## 4. 回测引擎

### 4.1 核心接口
```python
def backtest(prices: pd.DataFrame,      # 日期×资产 前复权收盘价
             target_weights: pd.DataFrame,  # 日期×资产 目标权重 0~1
             cost: Cost = Cost(),          # 成本模型
             initial_capital: float = 1_000_000) -> BacktestResult
```

### 4.2 计算流程（向量化）
1. **信号滞后**：`target_weights = target_weights.shift(1)` — t 日收盘算信号，t+1 日收盘执行。杜绝前视偏差。
2. **日收益**：`daily_returns = prices.pct_change()`。
3. **组合日收益**：`portfolio_ret = (target_weights * daily_returns).sum(axis=1)`。语义：`w.shift(1)` 后 `w_{t-1}` 对齐 `r_t`，即"昨日收盘设定的权重 × 今日收益"——昨日信号决定今日持仓，今日赚取今日收益。
4. **扣成本**：每次权重变动 `|w_t - w_{t-1}|` 乘以单边成本率，从当日收益扣除。
5. **净值**：`nav = (1 + portfolio_ret).cumprod()`，初始=1.0。
6. 结果封装为 `BacktestResult(nav, returns, weights, trades)`。

### 4.3 成本模型（cost.py）
- 佣金：万 2.5（最低 5 元，初始资金 100 万故最低费可忽略）。
- 印花税：ETF 免（0）。
- 滑点：万 1（单边）。
- **单边总成本 ≈ 0.035%**，往返约 0.07%。
- 资金假设：初始 100 万，可调。

## 5. 策略基类与 4 策略规格

### 5.1 基类
```python
class Strategy:
    name: str
    assets: list[str]        # 涉及标的代码
    def generate(self, prices: pd.DataFrame) -> pd.DataFrame:
        """prices: 日期×资产 收盘价(前复权). 返回: 日期×资产 目标权重(0~1, 每行和≈1)"""
```
**职责单一**：策略只产目标权重信号，不管交易、不碰成本——便于独立测试与组合。

### 5.2 S1 买入持有
- `assets=['510300']`，`generate` 返回全 1.0 权重（恒满仓）。

### 5.3 S2 双动量
- `assets=['510300','511260','511880']`（股/债/货币）。
- 规则：`stock_mom = price['510300'].pct_change(250)`；`bond_mom = price['511260'].pct_change(250)`。
  - 若 `stock_mom > 0 且 stock_mom > bond_mom` → 满仓 510300。
  - 若 `stock_mom > 0 且 stock_mom <= bond_mom` → 满仓 511260（相对动量切债）。
  - 若 `stock_mom <= 0`（绝对动量）→ 满仓 511880 货币（避险）。
- 月末调仓（取每月最后一个交易日信号）。

### 5.4 S3 均线趋势
- `assets=['510300','511880']`。
- 规则：`ma20 = price['510300'].rolling(20).mean()`；`ma60 = price['510300'].rolling(60).mean()`。
  - `ma20 > ma60` → 满仓 510300。
  - `ma20 <= ma60` → 满仓 511880 货币。
- 月末调仓。

### 5.5 S6 60/40
- `assets=['510300','511260']`。
- 规则：目标 60% 股 + 40% 债，**季末再平衡**（恢复 60/40）。
- 增强版可加 ±5% 阈值触发额外平衡（首版用纯季末再平衡，阈值留接口）。

## 6. 指标（metrics.py）

对每个策略净值序列计算，并与基准 S1 对比：

| 指标 | 定义 |
|---|---|
| 年化收益 | `(nav.iloc[-1])**(252/n) - 1` |
| 年化波动 | `daily_ret.std() * sqrt(252)` |
| 夏普 | `年化收益 / 年化波动`（无风险利率取 0，简化） |
| 最大回撤 | `(nav / nav.cummax() - 1).min()` |
| Calmar | `年化收益 / abs(最大回撤)` |
| 胜率 | 月度收益>0 的占比 |
| 换手率 | 年化权重变动和 |
| 相对基准超额 | `策略年化 - S1年化` |

## 9. 防前视偏差与回测纪律（命门）

1. **信号滞后 1 日**：`target_weights.shift(1)`，t 日收盘算信号，t+1 日收盘执行。
2. **复权**：东财 `fqt=1` 已前复权，直接算收益。
3. **公共起始对齐**：多资产策略取所有标的公共首个交易日，缺口记 NaN 不外推。
4. **成本计入**：佣金+滑点，单边 0.035%。
5. **生存者偏差**：4 策略标的均为 2012/2013 上市的长寿品种，全周期无生存者偏差；报告标注。
6. **数据真实**：行情一律走东财 push2his（已验证 14 年前复权），禁止估算/编造。
7. **诚实标注**：回测好≠实盘好，报告注明过拟合风险与参数依赖。

## 11. 非目标（YAGNI）

明确**不做**：
- 风险平价/全天候（需协方差估计，复杂度高，二期）。
- 布林带/网格/折溢价套利/配对交易（做空端 A 股实操受限）。
- 分钟级回测（日级足够）。
- 参数寻优/网格搜索（易过拟合，首版用报告约定参数）。
- 实盘交易对接。
