## 开发流程（强制）

> 本需求实施**必须走 superpowers 流程**。不要在生成需求后直接裸写代码。

实施时严格按以下顺序执行：

```
1. brainstorming   — 探索方案空间，不跳入单一实现
2. writing-plans   — 写出详细实施计划（含文件清单、API/数据结构变更）
3. TDD             — 先写测试，再写代码
4. executing-plans — 按计划逐步实施
5. code-review     — 自查 + 修复
```

**铁律：**
- 禁止跳过 TDD — 没有测试的需求不得推进到 IMPLEMENTED
- 禁止跳过 brainstorming — 不假思索的实现 = 返工
- 涉及 A 股数据的，仍走 `a-stock-data` skill

## 需求描述

`auto_experience_health` 任务（2026-09-09，记忆体系 Phase 3 首次 OpenViking 版执行）发现经验库迁移不完整，OpenViking 经验库无法独立支撑健康检查闭环：

1. **必需领域缺失独立条目（8 个）** — 这些领域在本地镜像 `harness/experience/*.md` 中存在，但 OpenViking `memories/experiences/` 无对应独立条目：
   - 投资领域：`跨市场映射`、`宏观数据公布日`
   - 短线领域：`做T`（核心纪律：开盘30分钟不操作/系统性普跌不做T/做T胜率校准等）、`事件套利`
   - 审阅领域：`逻辑一致性检查`、`完整性检查`、`常见错误模式`、`每日信号审阅清单`
   - → 结果：`viking_search` 按领域检索时这些领域无召回，分析前经验注入（小满量化经验记忆系统设计的核心机制）在这些领域失效。

2. **Schema 元数据字段缺失** — 全部 40 条 OpenViking 经验条目均无 `领域/状态/置信度/最近更新` 元数据字段（`_schema.md` 模板定义但迁移时未写入）：
   - 过时检测（第四步：>90 天未更新）无法执行 → 依赖"最近更新"元数据
   - 置信度健康（5A.2）只能从 Reflect 文本推断（全部"初始置信度中"），无法结构化统计
   - 矛盾/合并状态（`conflict`/`merged`/`deprecated`）无法标记与检索

3. **置信度更新循环（贝叶斯 T2）未在 OpenViking 落地** — 40 条经验全部停留在"初始置信度为中"，无任何条目有过 T2 证据链更新（无"证据链：{date} {来源} {事实} {置信度调整}"记录）：
   - 高置信度占比 0%（<20% 警戒线）→ 验证性复盘不足
   - 事件驱动沉淀规则（`_schema.md` 沉淀触发）在 OpenViking 侧未被执行

4. **镜像导出方向需修正** — 当前 OpenViking 条目为 09-08 迁移的**浓缩版**（Situation/Approach/Reflect 摘要），本地镜像文件（投资经验.md 423 行/短线机会经验.md 231 行/报告审阅经验.md 146 行）包含更丰富细节（案例、交叉引用、`<details>` 备份区）。若按 prompt 第五(A)步直接 OpenViking→本地 覆盖，将丢失 `跨市场映射`/`宏观数据公布日`/`做T`/`事件套利` 等章节 → 镜像导出方向应为 **本地→OpenViking 补齐**（先补全 OpenViking 侧，再恢复双向同步）。

## 期望结果

1. OpenViking `memories/experiences/` 补建 8 个缺失领域条目（内容从本地镜像对应章节迁移），领域标签完整（投资 9/9、短线 4/4、审阅 8/8）
2. 全部经验条目补齐 Schema 元数据（`领域`/`状态`/`置信度`/`首次沉淀`/`最近更新`），元数据写入方式可被健康检查检索（grep/元数据协议）
3. 建立 T2 证据链更新机制：复盘/周报中发现新证据时按贝叶斯规则更新对应条目置信度（中→高需 2+ 次独立验证；单次证伪中→低），置信度健康检查（5A.2）可结构化统计
4. 镜像导出方向修正：本地详细版 → OpenViking 补齐后，再评估是否恢复 OpenViking→本地 定期导出；过渡期本地文件保持为消费方完整镜像（`test_experience_health.py` 门禁保持通过：行数 ≤500/无重复头/必需章节齐全/北向标注/章节 ≤20 条）
5. 后续 `auto_experience_health` 可直接基于 OpenViking 元数据完成过时检测与置信度统计
