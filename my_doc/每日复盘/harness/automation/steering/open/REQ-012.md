## 需求描述

**问题**：9/10 当日最强板块之一「玻纤制造」(+3.77%，板块振幅 6.77%，主力净流入 +16.33 亿，8 涨 0 跌，九鼎新材涨停；同链玻璃玻纤 +2.53%/+16.76 亿）**在 09/10 早盘 staging 的板块扫描池中完全缺席**——staging 第五节仅列 7 项关注列表（光通信/煤炭化工/贵金属有色/种植业/半导体/军工/银行），全部为"前瞻性预判"通道，没有任何机制捕捉"当日已经启动但昨日未预判到"的板块。

这不是单日偶发：9/10 复盘异动扫描（上涨组振幅 TOP5）为 玻纤制造 / 航海装备 / 印制电路板 / 元件 / 集成电路封测，其中 **4 项不在早盘扫描池**。当日最强资金流入 TOP：印制电路板 +30.17 亿、元件 +30.17 亿、公用事业 +20.31 亿、建筑装饰 +18.01 亿、玻纤制造 +16.33 亿 —— 扫描池仅覆盖其中 0~1 项。

**根因**：扫描池为"纯前瞻"结构（只从外盘映射/消息催化/经验映射出发），缺少"纯反应"通道（从当日实际资金/振幅数据反推）。前瞻通道天然无法覆盖无预先催化但被资金选中的板块。

**需求**：非持仓板块扫描池改为**双通道**结构——
① **前瞻通道**（现有）：外盘映射 / 消息催化 / 资金确认 / 超跌反抽 / 防御红利 / 业绩驱动（REQ-003 六类）；
② **反应通道（新增）**：当日板块**主力资金净流入 TOP10** + **日内振幅 TOP10**（行业+概念，已按 REQ-004 去重、成交额≥100 亿过滤）→ 强制纳入次日扫描池候选，并逐条给出"是否可提前识别"归因。

**Related**: REQ-003（扫描池 6 类覆盖，CLOSED）、REQ-004（异动扫描改行业/题材版，CLOSED）。
