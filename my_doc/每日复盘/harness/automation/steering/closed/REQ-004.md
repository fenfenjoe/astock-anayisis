## 需求描述

用户反馈（2026-09-01）早盘分析/复盘分析报告存在三方面问题：

1. **早盘报告冗余展示**（应不生成）：
   - 头部元数据：生成方式 / 状态 / 数据源健康 / Staging来源
   - 一、我的持仓（可在 dashboard 等其他页面查看）
   - 八、操作清单（每日信号.md 中已有，重复）
   - 九、跨品种约束检查（语义不清，用户看不懂）
   - 十二、每日信号概览（每日信号.md 中已有，重复）
   - 12 节自检清单（内部质检项，不应展示在报告中）

2. **复盘报告冗余展示**（应不生成）：
   - 二、当前使用的策略
   - 三、数据口径
   - 五、全市场异动扫描（ETF 版）→ 改为对**行业、题材板块**扫描（ETF 扫描易重复，如 2026-08-31 复盘下跌组 TOP5 出现 4 只地产 ETF）

3. **运行问题工单化**：报告生成/自检中发现的问题（数据源健康、staging 新鲜度、异常数据如 159227 成本未复权浮亏 -62.84%）→ 报告内**简单提示**（1-2 行）→ 同时**提交 BUG/REQ 工单**供定时任务（harness_bug_auto_fix / auto_req_implement）处理。

## 期望结果

- 早盘报告仅含决策相关内容：前次预测回顾 / 海外传导 / 宏观研判 / 资金面情绪 / 板块机会扫描(+关注列表) / 持仓映射与操作判断 / 核心关注时间表 / 风险提示 + 尾部运行提示(有问题才出现) + 数据标注
- 复盘报告不再展示"当前使用的策略 / 数据口径"章节；"全市场异动扫描"改为行业/题材板块级（东财 clist 行业 m:90+t:2 + 概念 m:90+t:3，含板块指数 OHLC 计算振幅，行业优先+同名去重）
- 报告尾部"运行提示"节：问题一行提示 + 已提交工单编号；工单按 `lib/issue_tracker.py` 规则去重创建（同主题 OPEN 工单 → 更新处理记录，不重复建单）
- 逻辑巡检 C1/C3 关键词与新报告结构一致（顺带修复 BUG-008/BUG-009 关键词漂移）
