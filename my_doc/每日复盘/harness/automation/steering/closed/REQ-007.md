## 需求描述

**问题**：P0 信号触发后执行缺失连续重演——
- **9/2**：SIG-20260902-01（黄金 P0 减仓 1,300 份）触发（破 8.83）未执行
- **9/7**：SIG-20260907-02（工行 P0 减仓 500 份）触发（破 8.02 MA5，11:05 现价 7.99）未执行，14:45 截止前多次提醒仍"待填"

两次均为方向正确 + 触发精准 + 执行缺失——**瓶颈确凿在执行端**（依赖人工盯盘响应，无自动化保障）。已升级为系统性纪律缺陷（投资经验⑧）。

**根因**：
1. P0 触发依赖用户人工看到提醒后手动下单，无自动提醒/条件单/盘中核对机制
2. 触发记录在 `每日信号.md` 中标注"已触发（未执行）"，但无二次强制核验（如每 30 分钟复核未执行 P0 并醒目告警）
3. 收盘复盘才确认"未执行"，为时已晚（T+1 无法补当日卖出）

**目标**：P0 信号触发后，系统能自动或半自动确保执行（或显式记录"用户放弃"且复盘问责），杜绝"触发但静默未执行"。

## 期望结果

1. **P0 触发即显性化**：盘中检查在 P0 触发后立即生成高优先级提醒（醒目标记，如 `🚨 P0 待执行`），后续每个检查点（10:00/10:30/11:00/13:30/14:00/14:30）持续复核未执行 P0 并保持告警，直至执行/放弃/过期
2. **未执行 P0 的追踪**：`每日信号.md` 新增"P0 执行追踪"记录（触发时间 → 每检查点响应状态 → 最终结果），收盘复盘对"触发未执行"作零容忍问责（不做结果论豁免）
3. **条件单/提醒辅助**：可评估在盘中 prompt 中注入"P0 触发 → 建议设条件单（破位价/目标价）"的模板话术，降低对人工盯盘的依赖
4. **复盘指标**：P0 执行率（已执行 P0 / 已触发 P0）纳入信号质量仪表盘硬指标，连续 2 日 <100% 触发 P1 级告警
