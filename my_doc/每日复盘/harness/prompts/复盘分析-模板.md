## 三、数据口径（重要，先读）

> 以下口径与券商软件一致，复盘时严格遵守。

### 涨跌幅（标准口径）

```
涨跌幅 = (今日收盘价 - 昨日收盘价) / 昨日收盘价 × 100%
```

这是券商软件、腾讯财经等所有行情终端统一使用的计算方式。**复盘报告的涨跌幅必须用此口径。**

### 辅助指标

| 指标 | 公式 | 用途 |
|------|------|------|
| 开盘缺口 | (今开 - 昨收) / 昨收 | 判断高开/平开/低开幅度 |
| 日内波动 | (今收 - 今开) / 今开 | 判断日内走势方向与力度（低开高走/高开低走等） |

涨跌幅 ≈ 开盘缺口 + 日内波动（忽略二阶小量）。分析时先用涨跌幅判断涨跌，再用开盘缺口+日内波动拆解成因。

### 数据验证（执行前必做）

1. **价格跳变检测**：若任一 ETF 的 `|今收/昨收 - 1| > 15%`，必须排查是否发生份额调整（合并/拆分），确认除权后再比较
2. **数据源交叉验证**：早盘与收盘数据优先使用同一数据源（腾讯财经）；若混用 mootdx/腾讯，须交叉验证两源"昨收"是否一致
3. **昨收核对**：收盘腾讯的"昨收" ≠ 早盘报告中"现价"的参考基准时，需标注数据源差异

**触发准确性标准**：
- **准确触发**：触发条件满足时，市场方向与信号预判一致，执行后有正收益预期
- **误触发**：触发条件满足但市场方向与信号预判相反（条件设计过于宽松）
- **漏触发**：触发条件未满足但实际出现了信号预判的机会（条件设计过于严格）

**决策质量标准**（信号方向是否正确、触发条件是否合理）：
- **S (卓越)**：方向完全正确，触发条件精准，执行后获显著正收益
- **A (正确)**：方向正确，触发条件合理，避免损失或获得收益
- **B (中性)**：方向正确但触发条件需调整（过于严格/宽松）
- **C (偏差)**：方向基本正确但时机/仓位设置有问题
- **D (错误)**：方向错误，或逻辑依据已被证伪
- **F (严重错误)**：方向完全相反，执行会导致重大亏损

**执行质量标准**（用户是否严格按触发条件执行）：
- **A**：严格按触发条件执行，无犹豫/无提前/无滞后
- **B**：基本按触发条件执行，有轻微偏差（价格/时间偏差<10%）
- **C**：执行了但偏离触发条件较大
- **D**：应执行但未执行（错过信号）
- **F**：不应执行但执行了（违反信号纪律）

**升级质量评级（仅针对操作来源="观察升级"的信号，v3.0新增）**：
- **U-S**：升级时机精准，升级后信号获利
- **U-A**：升级方向正确，升级后信号平盘或微利
- **U-B**：升级方向正确但时机偏早/偏晚
- **U-C**：假突破升级——原观察信号本身不该触发（升级条件过于宽松），升级后亏损
- **U-F**：该升级但未升级——方向确认明确但升级条件未触发（升级条件设计错误）

5. **‼️ 代码-名称交叉校验（必须执行，防止 159227→恒生科技ETF 类错误）**：

   > staging 文件中的持仓表是 AI 手写的，代码和名称可能搞混。必须在归档前与权威来源 `config/持仓.md` 做机械化比对。

   ```bash
   cd E:/ideaworkspace/astock-anayisis
   python -c "
   import re, sys
   with open('my_doc/每日复盘/harness/config/持仓.md', 'r', encoding='utf-8') as f:
       config = f.read()
   code_to_name = {}
   for line in config.split('\n'):
       parts = [p.strip() for p in line.split('|')[1:-1]]
       if len(parts) >= 2 and parts[1].isdigit() and len(parts[1]) == 6:
           code_to_name[parts[1]] = parts[0]
   errors = []
   for sf in ['my_doc/每日复盘/harness/staging/今日-早盘分析.md', 'my_doc/每日复盘/harness/staging/今日-复盘分析.md']:

               content = f.read()
           for line in content.split('\n'):
               parts = [p.strip() for p in line.split('|')[1:-1]]
               if len(parts) >= 2 and parts[1].isdigit() and len(parts[1]) == 6:
                   code = parts[1]
                   name_in_staging = parts[0]
                   expected = code_to_name.get(code)
                   if expected and name_in_staging != expected:
                       errors.append(f'{sf}: {code} staging=\"{name_in_staging}\" config=\"{expected}\"')
       except FileNotFoundError:
           pass
   if errors:
       print(f'[FAIL] {len(errors)} code-name mismatches, fix before archiving:')
       for e in errors: print(f'  {e}')
       sys.exit(1)
   else:
       print('[PASS] Code-name validation passed')
   " 2>&1
