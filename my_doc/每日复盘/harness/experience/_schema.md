# 经验条目 Schema 模板（量化经验 · OpenViking 格式）

> 本模板定义 OpenViking Experience 的量化经验条目结构（Situation/Approach/Reflect 三段式
> + 置信度 + 证据链 + 元数据）。日常沉淀按本模板写入 OpenViking（`viking_remember`,
> category=experiences）；本文件作为模板参照（过渡期镜像保留）。
> 写法约定：正文所有 OpenViking 路径省略协议前缀（`user/default/...` 即 `<viking协议>://user/default/...`）。

---

# 经验标题（一句话：场景 + 结论）

## Situation（触发场景）
- 市场环境：{普涨/普跌/震荡/风格切换/外盘冲击...}
- 触发条件：{板块/信号/标的/数据形态的具体量化条件}

## Approach（应对方法）
- 分析动作：{早盘/盘中/复盘时怎么做}
- 操作纪律：{具体的可执行规则，含阈值/触发价/仓位}

## Reflect（验证与校准）
- 证据链：{每次验证/证伪记录，可多条。格式：{YYYY-MM-DD} {来源} {事实} {置信度调整}}
- 校准结论：{规律有效 / 需修正（收窄适用范围）/ 已证伪}
- 置信度：{高 / 中 / 低}（贝叶斯后验，随证据更新）

## 元数据（供检索与融会贯通）
- 来源：{morning_analysis | intraday_check | evening_review | signal_quality | forum | book | chat}
- 领域：{市场判断/跨市场映射/数据纪律/信号设计/做T/板块扫描/宏观/超跌反弹/...}
- 状态：{active | deprecated | merged | conflict}
- 关联：{相关经验 URI 列表}
- 首次沉淀：{YYYY-MM-DD} | 最近更新：{YYYY-MM-DD}

---

## 贝叶斯更新落地规则（沉淀时遵守）

| 场景 | 动作 |
|------|------|
| 新条目 | 默认置信度 = **中** |
| 单次验证 | 中 → 高（**不一次打满**，需 2+ 次独立验证） |
| 单次证伪 | 中 → 低（**不删除**） |
| 低置信度再被证伪 / 90 天无更新 | 状态 → `deprecated` |
| 经验冲突 | **双方都保留**（不删旧），各标 `conflict_with`，由周三健康任务/用户裁决 |

## 沉淀触发（事件驱动）

- **T1 新规律**：本次分析/复盘发现可复用新规律（与既有经验无重复）→ 新建条目。
- **T2 旧经验被证伪/需校准**：本次事实与既有经验冲突或出现新证据 → 更新对应条目的
  证据链 + 置信度（贝叶斯调整），不改写结论本身。
- **两者皆无**：不写（禁止每次分析都沉淀）。

## 检索消费（分析前注入）

- 早盘/盘中/复盘分析前：按**当日相关领域**检索（市场环境/持仓板块/做T纪律/信号设计），
  top-N 纳入分析依据（叠加插件自动 recall，控制条数避免挤占上下文）。
