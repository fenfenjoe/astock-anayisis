## 三、删桶操作步骤（用户控制台执行，不可逆）

**火山引擎控制台 → 对象存储 TOS**（地域：华北2-北京 / cn-beijing）：

1. **删前核实**（1 分钟）：
   - 本机 `my_doc/每日复盘/每日调仓.md`、`harness/config/持仓.md` 存在且最新
   - `reports/` 目录存在
   - Supabase 云库 reports/holdings 齐全（dashboard 持仓页可正常查看）

2. **进入桶**：桶列表 → 点击 `astock-data`

3. **清空对象**（桶非空删不掉，必须先清对象）：
   - 「全部对象」→ 全选 → 删除
   - 共约 648 个对象 / 738.88 MB（其中 `sqlite/` 728 MB 为旧快照，可全部删除）

4. **删除桶**：返回桶列表 → `astock-data` → 更多 → 删除 → 输入桶名确认

5. **（可选）清理 AK/SK**：访问控制 → AccessKey → 停用/删除（若该 AK 仅此桶用）

## 五、重启提示

当前运行中的 dashboard + agent（PID 见 `scripts/.pids/`）是旧代码。删桶前后应重启到新代码：

```powershell
# 停止
powershell -ExecutionPolicy Bypass -File scripts/start_all.ps1 -Action stop
# 启动
powershell -ExecutionPolicy Bypass -File scripts/start_all.ps1 -Action start
```

> 凭据已清空，旧进程当前只能降级本地运行，不会真写 TOS；重启后完全脱离 TOS。
